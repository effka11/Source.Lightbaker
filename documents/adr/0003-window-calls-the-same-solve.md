# У окна нет своего света

Окно и запекание вызывают один расчёт. Меняется только бюджет лучей. Отдельной картинки — растеризации, точечных ламп, своего трассировщика — нет.

Быстрый чужой предпросмотр разойдётся с файлом, который загрузит Garry's Mod. Дешевле мало лучей в том же расчёте, чем второй алгоритм.
